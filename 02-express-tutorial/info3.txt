In HTML, a <form> element is used to collect user input 
and submit it to a server for processing. It serves as a 
container for input fields, buttons, and other
 interactive elements. Forms are commonly used for login 
 pages, contact forms, search bars, and more.

 <form action="/login" method="POST">
action="/login" – Specifies the URL where the form data 
will be sent upon submission.

method="POST" – Defines the HTTP method used for 
submission (commonly POST or GET).

<input type="text" name="name" id="name" autocomplete="false" />
Allows users to enter their name.
The name="name" attribute is used to identify the input 
when submitted.

<button type="submit" class="block">submit</button>
Sends the form data to the server when clicked.

Without express.urlencoded(), Express does not parse 
application/x-www-form-urlencoded data
 (which is the default format when submitting an HTML form).

 const express = require('express')
const app = express()

let {people} = require('./data')

app.use(express.static('./methods-public'))

app.use(express.urlencoded({extended: false}))
//it parses incoming requests with unrlencoded payloads and
//  is based on body-parser.

app.get('/api/people',(req,res)=>{
    res.status(200).json({success:true,data:people})
})

app.post('/login',(req,res)=>{
    const {name} = req.body
    if(name) {
        console.log(req.body);
        return res.status(200).send(`Welcome ${name}`)   
    }
    
    res.status(401).send('Please provide creds')
})


app.listen(2006,()=>{
    console.log("Server is listening on your bday port")
})

If you submit the form from the browser, the data is 
sent as URL-encoded format (application/x-www-form-urlencoded).

If you send a request from Postman, 
you can send data in different formats, including JSON.


hence the line app.use(express.json()) is important
